# 识海协议宇宙

> **一个「世界观编译器」。**
> 给一个「**场 + 守恒 + 不可逆**」，就长出一个自洽的世界——
> **物理、修真、克苏鲁、怪谈、无限流，都只是"输入不同"。**

---

## 这是什么

一套**世界观设定集**（worldbuilding bible），写在三层之上：

> **一条公理 → 全部机制 → 任意世界。**

- **它的野心**：不是"解释魔法"，而是**"把物理降级成一种世界观选项"**——然后让所有玄幻**共享同一个底层宪法**。
- **它的底**：只有一条公理——**最省（最可压缩的活下来）**。守恒、不可逆、时间、污染、生死……**全是它的下游**。
- **它与物理兼容**：物理世界 ＝ 其中"一个档位"（能量守恒 + 熵增）。**框架没推翻它，只是把它降为一种选择**。
- **它承认代价**：没有免费的奇迹；每一份逆天，都在暗处欠着一笔。

## 它能收什么

这套底层**不挑题材**——它挑"**场 + 守恒 + 不可逆**"：

- **体系**：传统神系 · 三界 ／ 亚伯拉罕系（一神教）
- **类型**：克苏鲁 ／ 规则怪谈 ／ 无限流
- **收法**：找它的 **场 + 守恒 + 不可逆** → 挂到 `01 / 02` 的零件上（见 [`推演备忘.md`](推演备忘.md)·五）

## 三个最省字的入口（懂行的人一看就通）

- **干 ＝ 场 + 守恒 + 不可逆**；其中只有"场"是平凡的，**守恒与不可逆都是"最省"逼出来的**；
- **污染 ＝ 一处不自洽 → 压缩重构**（就近／愿望变味／大能者困境，三条推论）；
- **锚 ≈ 带主体的选择公理**：世界"**必有锚**"推得出，"**锚是什么**"推不出——**那一步是非构造的"选"**。
